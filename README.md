# ROS1智能导航小车

面向室内二维建图与导航的差速移动机器人项目，采用Linux上位机与ESP32-S3底盘控制器协作的架构。上位机基于ROS1处理激光数据、地图、定位与路径规划，底盘控制器负责电机闭环控制和传感器采集，双方通过Wi-Fi交换运动指令与状态数据。

## 项目组成

- **底盘运动控制**：基于ESP-IDF与FreeRTOS组织控制任务，结合编码器反馈、差速运动学和轮速PID控制双轮电机。
- **无线数据通信**：通过TCP协商连接，使用UDP传输底盘状态与雷达数据，配合Python虚拟串口桥接接入ROS驱动。
- **机器人状态与模型**：包含轮速里程计、MPU6050采集、URDF模型、TF坐标变换及标定工具。
- **激光建图**：接入YDLIDAR X2雷达，提供Cartographer建图配置及地图保存功能。
- **定位与导航**：采用AMCL进行地图定位，通过move_base组织全局规划、局部路径跟踪和避障，包含TEB与DWA控制配置。

## 硬件与技术栈

硬件采用ESP32-S3、双轮差速底盘、编码器电机、MPU6050、YDLIDAR X2及OLED显示屏，Linux电脑承担上位机计算。

软件使用C/C++、Python、ROS1、ESP-IDF、FreeRTOS、Cartographer、AMCL和move_base。代码按ROS功能包、底盘固件、通信脚本和雷达SDK组织。
